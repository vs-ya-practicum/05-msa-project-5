# Задание 3. Экспорт данных PostgreSQL по расписанию

Программа на TypeScript выгружает данные таблицы `shipments` за предыдущий календарный день по московскому времени в CSV-файл. Kubernetes CronJob настроен на ежедневный запуск в **20:00 Europe/Moscow** в пространстве имён **`task-3`**. PostgreSQL работает в Minikube. CSV-файлы сохраняются на постоянном томе и доступны после завершения Pod экспорта.

Тестовая БД содержит 100 записей: 90 за вчера, 5 за сегодня и 5 за позавчера. Даты определяются при инициализации БД.

## Состав решения

- `realization/src/export.ts` — программа экспорта данных в CSV.
- `realization/package.json` и `realization/tsconfig.json` — зависимости и настройки сборки TypeScript.
- `realization/Dockerfile` — конфигурация сборки Docker-образа программы.
- `realization/db/init.sql` — создание таблицы и заполнение тестовыми данными.
- `realization/k8s/` — конфигурации пространства имён, PostgreSQL, CronJob, подключения к БД, хранения CSV и вспомогательного Pod для чтения результата.

На [скриншоте](working-export-stack.png) показаны работающий Minikube, расписание CronJob, успешно завершённые Job и Pod, логи с результатом выгрузки 90 записей за `2026-10-31`, начало CSV-файла и результат подсчёта строк — 91, включая заголовок.
